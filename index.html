WCAG 2.1 Level AA Accessibility Audit Summary

The accessibility audit revealed severe non-compliance with WCAG 2.1 Level A and AA standards across forms, media links, and interactive triggers.

WCAG 1.3.1 Info and Relationships (Level A) - Critical Failure

22 out of 23 input labels on `/careers/qa-testing-intern` and 5 out of 5 labels on `/contact` have no `for` (or `htmlFor`) attribute and do not wrap their respective `` elements. Screen readers cannot associate field instructions with input fields.

WCAG 4.1.2 Name, Role, Value (Level A) - High Failure

Multiple form controls in the career portal lack accessible names and `name` attributes. Mobile hamburger button contains only text ligature "menu" without `aria-label="Toggle Navigation"` or `aria-expanded` state tracking.

WCAG 2.4.4 Link Purpose in Context (Level AA) - Medium Failure

Social media links (LinkedIn, X, Instagram, Facebook) in the global footer have no textual content or `aria-label`. Assistive technologies announce them as "empty links".

WCAG 1.4.3 Contrast (Minimum) (Level AA) - Low Warning

Several micro-captions with CSS classes `text-[10px] text-slate-500` or `opacity-60` exhibit contrast ratios below 4.5:1 against slate-900 background.
